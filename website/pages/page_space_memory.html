§1　原典：他把话说到了哪一步

这一节先把原文摆齐。审查最怕的不是结论不同，是审的不是人家说的那句。以下九条按原文顺序，一字未改。

「信息的定义：信息是物质【由物体和空间组成】的运动形式。」

「宇宙中任何物体粒子储存或者携带的信息总是有限的。」

「宇宙中任意一处空间可以储存整个宇宙以前的、现在的、未来的所有信息。换句话，任意一块空间可以无限存储信息。」

「或者说：宇宙任意一处有限空间区域里，都可以存储无穷多的信息。」

「用逻辑证明如下：」

「物体周围空间以光速向四周发散运动，可以把这个物体的一切信息带到周围空间里。由于光速运动的三维空间，沿运动方向的空间因为光速运动导致长度缩短为零，变成了二维空间。」

「所以，光速运动空间可以把物体所有的信息刹那间带到宇宙任意一处空间里，而不是大家所想的那样是以光速一步一步的传播。」

「物体的一切信息实际存储在二维空间里。由于二维空间是零体积，可以和宇宙任意一处三维空间保持着零距离，所以，二维空间中存储的信息，可以弥漫在宇宙任意一处空间里。」

「因为时间是我们观察者的感觉，如果没有我们观察者，不存在时间，宇宙中亿万年前和亿万年后，所有的信息都可以存在于空间的一个点上。」

「三维空间中发生的信息，可以保存在二维空间中，严格的证明，可以用场论中的高斯定理。」 ——《张祥前的超前物理理论》第十七节，原文第 422–448 行
「我们现在存储信息也是在利用空间，我们有一个关于空间与信息的定理：宇宙任意一处空间，可以存储整个宇宙今天、以前、以后所有的信息。换句话，空间存储信息的能力理论上是无穷大的。」

「只是，在实际操作的时候，空间存储信息的能力受到其他一些条件制约，虽然不是无穷大，但是，空间存储信息的能力在你们地球人看来，也是十分恐怖的。」 ——《果克星球奇遇记》第三章「果克星球的超光速通讯」，原文第 700–702 行

注意第二段里那句「在实际操作的时候……虽然不是无穷大」。他自己已经先把理论口和无极口分开了：定理说无穷，操作说有限。这句话是整场审查的入口——它把「不可证伪的本体论」和「可检验的工程命题」一刀两断，而本站只审后一半。

他给出的「证明」其实只有三步

第一步　三维空间以光速运动  →  沿运动方向长度收缩为零  →  变成二维
第二步　二维空间零体积     →  与任意三维空间「零距离」     →  可弥漫任一处
第三步　凡三维发生的信息均可存于二维          →  故任意一点含全宇宙
        （他注明：严格证明可用高斯定理）

三步各自都有问题，且性质不同：第一步是标准物理的正确引用（洛伦兹收缩确实在 v→c 时退化），第二步是两次概念替换（体积→距离→可达性），第三步是量纲与定理的双重误用。下面 §4 逐条拆。

§2　翻译：把「存」拆成五件事

「空间能存信息」这句话之所以听上去成立、又始终落不了地，症结在「存」是个动词，而动词要求有内外之分。工程上，一次真正的存储必须同时满足五条，缺一条就退化成「含」：

要件必须做到什么张氏主张给了没有
① 可制备能主动把载体置到某个指定态，而不是只能被动接收余晖无。空间是「弥漫」的，没有置态动作，也没有置态装置
② 可区分至少有两个可分辨的态，且能读出「是哪一个」无。他说「信息弥漫在任一处」，但没说什么态与什么态区分
③ 可寻址能指定「这一处」而不扰动别处无，且与主张直接冲突：每一点都含全部，就没有「这一处」
④ 可复位用完能擦回空白，准备下一次写入无。且他明说「没有观察者就不存在时间」，复位这个动作连时刻都定不了
⑤ 有环境有一个外部接收擦除排出的熵（否则热力学第二定律被破坏）无。载体放大到宇宙，环境随之消失，kT ln2 里的 T 都写不出来

这一节的一句话

五条要件不是「难度」，是「定义」。「存」＝可制备＋可区分＋可寻址＋可复位＋有环境；五条都不给，「空间能存信息」就只剩「空间里发生着演化」——那是含，不是存。含是状态，存是操作。

§3　三条定律级判决

之所以叫「定律级」，是因为下面三条不是工程难不难的问题，而是在任何技术水平下都不能被绕开的性质。张氏主张要成立，必须至少破掉其中一条；破不掉，就只剩「换个说法」。

判决一：真空没有可寻址自由度

量子场论里真空＝场的基态。基态不能通过状态变化释放能量、不输出信号。要写入，就必须激发场；一激发就产生粒子——于是瞬间退回他自己判为「落后」的「用物体粒子存」那一层。

这句话不是文字游戏，它把主张逼到一个二难上：要么空间是空的（那就没东西可写），要么空间被激发（那就不是「空间本身」在存）。世上没有第三个选项。

判决二：容量不是无穷，而且不按体积算

这是本节最反直觉、也最有分量的一条。贝肯斯坦界与黑洞熵给出的最大信息量是：

S ≤ 2πk_B·R·E / (ℏc)          贝肯斯坦界（Bekenstein bound）
S = A / (4 l_P²)                黑洞熵 · 每 4 个普朗克面积约 1 bit

⇒ 最大信息量 ∝ 边界「面积」，不是「体积」

「按面积不按体积」这一点，恰好是张氏「零体积二维面」这句话最像正经物理、又最致命地相反的地方：全息原理确实说信息编码在边界上——方向对上了；但全息原理同时说密度有上限、总量有限——这一条被换成了「无穷」。§4 第一条断裂就出在这儿。

判决三：读、写、擦、传，四件事都要付账

  • 擦：擦一比特至少耗散 kT ln2，这是地板，不是效率问题（§8 专讲）。
  • 读：读要测量、要记结果、要把辅助比特复位——读里含着擦，所以也交税。
  • 写：写入保真度要么付能量，要么付冗余，二者必选其一。
  • 传：任何信息的传递都受因果律约束，最快是 c。量子纠缠不能用来传信息——这条没有豁免。

张氏那句「刹那间带到任意一处，而不是以光速一步一步传播」，正面撞在第四条上。它同时也是撞在第一条判决和他自己的公设上（见 §4 第二条断裂）。

§4　他自己体系里的三处断裂

这一节是全篇最要紧的部分，因为它不需要引用任何外部物理——只用他自己的公设和他的结论对照，就能看出三处接不上。对一本自建体系而言，内部一致性是比外部对错更低的门槛，过了这关才轮得到谈物理。

断裂一：有面积就有限，无穷就没面积

他的说法

信息存在二维空间里；二维空间零体积，与任一处三维空间零距离，故可弥漫全宇宙，容量无穷。

不引用外部物理就能看出的问题

「二维面」这个词自带面积。只要有面积 A，就受 A/4l_P² 限制，必然有限；若要容量无穷，A 必须无穷大——那就不是一个能被「零距离接触」的面。反过来，若它真「零体积到连面积也没有」，则 A→0，容量→0。

结论：这是一个闭合的二难——有面积就有限、无穷就没面积，两头都不通向「任意一点存全宇宙」。他试图用「零体积＋零距离」跳到「无穷」，跳过的正是「面积」这个唯一能算容量的量。

断裂二：「刹那到达」与「空间以光速运动」不能同时成立

他的第一公设是空间以矢量光速 C 相对观测者运动。而他的结论是「信息刹那间到达任意一处，不是以光速一步一步传播」。

若载体（空间）本身以光速运动  ⇒  它跨越距离仍要时间 t = d/c
若结论要求 t = 0            ⇒  载体速度必须为无穷大，与公设 C 直接冲突

他用来打通的机制是「长度收缩为零」。但洛伦兹收缩有两处不能这样用：其一，γ→∞ 只在 v→c 时发生，且需要无穷能量，是个极限而非可达状态；其二，收缩发生在运动方向上，是「长度变短」，不是「与所有点距离为零」。把「长度→0」读成「距离→0」，再把「距离→0」读成「可达任意点」，两次都是换概念，两次都没有证明。

断裂三：高斯定理证不出这句话

他写「三维空间中发生的信息，可以保存在二维空间中，严格的证明，可以用场论中的高斯定理」。但高斯定理是：

∮_S E·dA = Q / ε₀        （S 是闭合曲面，围出体积 V）

它说的是：闭合面上的「通量积分」＝ 内部「源」的总量
它没说的是：面能「记住」内部发生过什么

两处不合：① 高斯定理要求 S 是闭合曲面并围出体积，一个「零体积的二维面」不满足前提；② 它给出的是一个标量积分值（通量），不是一份可寻址的编码。通量守恒 ≠ 信息编码——把前者当后者，正是本站反复记录的那类操作：借真实数学框架，承载非数学结论。这一条与首页「40 项对照」里的判定同类，只是这次借的是高斯定理。

三处断裂的共同形状

三次都是把一个真实的、有条件的结论，去掉条件后放大成无条件结论：
长度收缩（有条件：v→c，沿运动方向）→ 距离为零（无条件）
面积承载比特（有条件：密度上限 1/4l_P²）→ 无穷容量（无条件）
通量守恒（有条件：闭合面、积分值）→ 信息存储（无条件）
这个形状，和他推导「四种力」时把「一次乘积求导」放大成「四个物理力」，是同一个手法。

§5　五圈闭环：每次补救都撞回同一堵墙

接下来这一段是这场对话最精彩的部分：提问者没有停在「空间存信息」，而是连续换了五个载体去救它。每换一次，就补上一个漏洞；每补上一个，又露出另一个——五圈绕回来，墙还是那一堵。

图 1｜五圈闭环。每一圈都是对上一位的下一次补救，每一次都补对了某个洞，然后撞回同一堵墙。这张图是本文的骨架，后面 §6–§9 都是这五圈里某一圈的展开。

把五圈拆成一句一句

圈这次的补救补上了什么又被什么挡住
1载体不是晶体，载体＝宇宙本身不用另找介质，字面上没被驳倒——Landauer 从没规定载体得多大没有外部执行写入；整体只有一个态，可区分态数＝1，信息量 log 1 = 0；kT ln2 里的 T 是环境温度，环境没了公式写不出
2那就让黑洞吃掉一切，视界就是边界内外之分终于有了：掉进去算里，我们算外；写入者、环境、可区分态都到位无毛定理：外面只读到 M/J/Q 三根毛，扔《道德经》和扔冰箱外观一样；只记「多少熵」，不记「哪本书」
3不擦了，留在宇宙背景辐射里环境还回来了，2.7K 就是那个 T，账本重新能算CMB 一成为「环境」，宇宙整体就不再是载体 → 又退回「子系统＋外面」；且热化把「哪件事」压成「多热」
4等未来技术把它捞回来信息确实没被删除（幺正演化），只是被搅成极难解开的纠缠解码复杂度随规模指数涨（已有「计算相变」的写法）；且要把全局态记下来得同等规模草稿纸，而读者也在宇宙里——没有岸可站
5换小载体：水晶头骨内外终于干净了：器物是内，我们是外，有仪器有边界内外一干净，缺的那环立刻露出来：没人写进去，读什么？（§9 详述）

这五圈值不值得记？值得

因为它演示的不是「一个错误主张被驳倒」，而是一个正确直觉被反复错误的补救方式拖住。提问者每一圈的方向都对——找边界、找环境、找读法——只是每找到一样，就把「载体」换一次，于是每换一次都要重付一次税。真正该做的是第三圈那句话反过来读：别等它热化，趁信息还是信息的时候接住。§12 讲的就是这一半。

§6　过去 · 现在 · 未来 三栏

「任意一处空间含全宇宙今天、以前、以后所有信息」这句话，拆成三栏之后红线的位置就非常清楚了。三栏不是三种难度，是三种性质：过去是「有没有」的问题，现在是「在不在」的问题，未来是「定没定稿」的问题。

栏能拿到什么为什么只能拿到这些代价 / 判据
过去 有限摘要六个宇宙学参数级别的「配方」；CMB 十万分之一的涨落谱 宇宙 38 万岁前是光子—重子等离子体，光子走一小段就被散射，对光不透明——那是一堵「光墙」。能看见的最远处就是最后散射面，一张 2D 球壳，不是全史 热化是多对一：把「哪本书」压成「多热」。μ/y 畸变能反推「某个时期注入了多少能量、大概哪个红移」，给的是量与时期，不给「谁、哪本」
现在 不在光锥里只有沿途被改动的积分投影 我们收到的光子全部来自过去光锥；「此刻的全宇宙」绝大部分在粒子视界之外，因果上不可达。可观测宇宙是以我们为中心的视线极限，不是一堵墙，但它的另一边没有数据能到我们这儿 能读到的「后来」只是引力透镜、SZ 效应、银河尘埃的积分效果——是「这束光一路被怎么动过」，不是「宇宙现在长什么样」。没有第二个「现在」
未来 尚未定稿原则上不可由过去数据推出 三条独立否决：①量子测量——Bell 1964 ＋ 2015 无漏洞实验排除定域隐变量，结果原则上只有概率幅；②混沌——即使完全决定论，初始误差按 Lyapunov 指数放大；③信息论——互信息一旦衰减，数据处理不等式说任何变换都追不回 「空间含未来」要成立，得先答应三件物理没给的东西：未来已定稿、有一份完整初态、有一个站在宇宙外面读它的观察者。第三件正好是 §5 那堵墙

一句话记住

过去 = 有限摘要（有配额，无目录）
现在 = 不在光锥里（不是看不清，是到不了）
未来 = 尚未定稿（不是算不出，是没定）

这三句合起来，正好是「任意一处空间含全宇宙今昔未来」这句话能给出的最大善意版本：它承认了三栏的差别，同时把「含」保留在演化律层面——宇宙能含演化律，不能给未来清单；能含信息，不能存信息。

顺带说清「全息原理」这张牌：它支持一半，反对一半

每次讨论到这儿，最容易被拿出来的是全息原理——「正经物理也说空间存信息啊」。它是这句话最接近主流的一个版本，但给的答案清清楚楚是四个「不」：

全息原理怎么说与张氏这句话的关系差在哪
信息编码在边界（面），不在体内任意一点方向对上了：他也说「信息存在二维空间」他说「零体积二维面弥漫任一点」；全息说的是边界编码体信息，不是每一点都存
非局域冗余，像量子纠错码，抹掉几个边界比特不丢体信息他说的「弥漫」有点像这个冗余编码 ≠ 随机存取；全息给的是「扰动容忍」，不是「随便点一下就能读」
容量有限，A/4l_P²正面冲突：他写的是「无穷」这是 §4 断裂一；也是全息原理没法替他背书的地方
只在反德西特时空严格成立；我们宇宙是德西特，没有那种方便边界连「最像的一支」都还在猜想状态所以它连「支持一半」都要打折：这一半是「有条件成立的一半」

结论：全息原理不是张氏这句话的证据，而是它的限制条件清单。它把「空间存信息」从一个浪漫断言，压成一句有配额、有边界、有适用时空的技术命题。能借的只有方向，借不到「无穷」。

§7　CMB：读得出体检报告，读不出日记

这一节回答一个非常具体的问题：今天到底能不能从宇宙背景辐射里读数据？答案是能，而且这是当代精度宇宙学的主力——但读出来的东西与「恢复记忆」之间，差着一个根本性的东西：统计量 vs 事件。

现在真能读出的东西

  • 它是什么：宇宙微波背景是 2.725 K 的近完美黑体，是宇宙约 38 万岁时光子第一次自由飞行留下的「最后散射面」快照，温度起伏只有约十万分之一（ΔT/T ~ 10⁻⁵）。
  • 读出了什么：就靠这十万分之一的斑点，Planck 把宇宙的「体检指标」定到亚百分点级——年龄 137.97 亿年、空间平坦到 0.4% 以内、普通物质 4.9% / 暗物质 26.8% / 暗能量 68.3%，还有哈勃常数、中微子有效种数、再电离时期。声学峰的位置与高度分别对应曲率、重子密度、暗物质密度。
  • 还在升级：智利西蒙斯天文台多台望远镜已全量上线、探测器数万级，目标是找暴胀留下的 B 模偏振、数星系团、用引力透镜反推物质分布、称中微子质量。还有个巧用法：把 CMB 当背光灯，看它穿过后来 138 亿年的结构时被怎么偏折、怎么散射，反推中途的物质演化。

为什么这跟「恢复记忆」不是一回事

四个绕不过去

① 热化把「哪件事」抹成了「多热」。黑体谱意味着光子早被反复散射搅成一锅热汤，记录的是温度与涨落的统计谱，不是事件清单。

② 只有一张 2D 球面。之后的事只能靠沿途被改动的积分效应间接猜；未来那部分，这束光里压根没有。

③ 只有一份天空。这叫宇宙方差：功率谱在大尺度上独立样本数 = 2ℓ+1，四极矩 ℓ=2 只有 5 个模式，误差 ∝ 1/√(2ℓ+1)。不是望远镜不够好，是我们只有一个宇宙可以采样，造再贵的仪器也消不掉。

④ 还得先擦掉噪底。银河尘埃、大气水汽、星系团热电子（SZ 效应）全得建模减掉，剩下那点才是原初信号——这一步已经在不停测量、复位、丢弃辅助数据。

一句话对照

能从背景辐射里读出的，是
「烤箱当年几度、配方比例多少」，
不是「那天谁把什么放进了烤箱」。

而且连这也不算免费：你测、存结果、把草稿复位，每一步都在交 kT ln2 那笔遗忘税（§8）。

若把「背景」放宽到引力波背景、宇宙中微子背景，目前连直接探测都还在攻关，更谈不上读数据。

AI 接得进去吗？接的是数据表，不是场

这是对话里最容易被误读的一问。答案是能，而且已经在跑——但必须先把「接入」拆开：AI 接入的是我们的观测数据，不是宇宙背景场本身。这两件事差着一整套物理。

AI 在 CMB 流水线里干什么具体边界
擦噪底CNN 做银河尘埃前景扣除；混合网络把残留功率压到传统 ILC 的约 1/7作者自己强调：换一套仿真，泛化仍是关键难题
去透镜神经网络重建未被透镜扭曲的 B 模，再做无似然推断直接估张量标量比 r依赖对透镜势的先验模型
从图到参数仿真推断 ＋ normalizing flows，把全天图压成几个宇宙学数压得越狠，可反推的越少
多挤统计量高阶非高斯统计 ＋ 高斯过程模拟器，把 Ωm、As 的不确定度再降约 40%/38%仍是统计量
一个值得记的做法有团队刻意只用「不含信号」的数据组合去训练 ML，再与 ILC 拼接学界自己很清楚这条边界：怕模型把原初信号「顺手编掉」

而不能的那一半，跟算力无关，是三道墙：

  1. 数据里没有的比特，模型变不出来。信息论的数据处理不等式：X → Y → Z 这条链上 I(X;Z) ≤ I(X;Y)，后续处理不可能创造上游不存在的信息。更严的版本把「Z→语料→权重→输出」写成马尔可夫链，结论对无限精度权重、无限算力、神谕级训练都成立。一句话：运行更久不会扩大一个函数的值域。
  2. 样本数 = 1。这不是算法差，是宇宙方差。Planck 的温度涨落已经摸到这条地板——再造更灵敏的温度传感器，对大尺度宇宙的新增信息是零。像只准你抛一次硬币却要判断它公不公平。
  3. 那层「日记」在物理上就不存在。CMB 近似高斯随机场，全部信息由功率谱完整描述。也就是说「体检报告」不是我们读得不够细，是这份档案当初就只写了统计栏，没有事件栏。

怎么一眼识破「AI 考古」类说法

一个机械的检验办法：换个随机种子或先验，看它讲不讲同一个故事。真读取必须可重复——同一份数据、不同先验、不同模型，结论应收敛。若换个种子就换一套叙事，那不是读取，是生成。
这条判据比任何术语都好用，因为它不要求你懂物理，只要求你重复一次。

§8　遗忘税 kT ln2：小白版

这一节之所以要单独留一块，是因为整场审查最后都落在这个数上：kT ln2 ≈ 2.87×10⁻²¹ J（300 K）。它小到可以忽略，却不能被绕过。它是这篇审查里唯一一个「地板」——别的都是难度，只有它是边界。

图 2｜遗忘税。热力学第二定律不许「可能性」凭空消失：2 种可能压成 1 种，少掉的那份必须以热的形式排到环境里，最小份量就是 kT ln2。图里第二步「不记录原值」是关键——只要记了，就没有不可逆，就不交这笔税（可逆计算的全部动机在此）。

为什么它对这个主张那么致命

因为张氏这句话的整个卖点是「不用介质、不用能量、无限容量」。而 kT ln2 恰好把三个「不用」逐个对上：

不用介质  ⇒  就没有「态」可复位  ⇒  也没有「擦」这个动作
不用能量  ⇒  但写入保真度要么付能量、要么付冗余
无限容量  ⇒  但每 4 个普朗克面积 1 bit，容量按面积算，且有限

所以那个数看着小到无害，实际是这句话的判决书：它不是「能量不够」，是「这笔账必须有借方」。

"宇宙不收存储费，只收遗忘费" —— 这句要补半句

对话里那句金句只说了一半。完整版是：
宇宙不收保管费，也不收预知费；它收的是你想把它重新翻出来那一下。
因为「恢复」不是白看一眼：你得测量、记下结果、把辅助比特复位成空白好准备下一次。纠错本身就是在当麦克斯韦妖，每一步都在擦。所以遗忘费不只在「删书」时收，它在「翻书」时也收。你以为只保留了「存」，其实「读」里也含着「擦」。

§9　水晶头骨：四笔账与「方向是反的」

这一问之所以值得单列，是因为它把前面那串抽象难题换成了一个更友好的形状：不再拿整个宇宙当载体，换成一件具体器物。头骨是内部，我们是外部，有仪器、有边界、有观察者——内外之分终于齐了。

可恰恰因为齐了，缺的那一环反而露出来了：没人写进去，读什么？

四笔账

账事实结论
① 十三颗 「集齐 13 颗能解开宇宙奥秘／阻止世界末日」是20 世纪神秘主义叙事，后来才与 2012 末日绑在一起——「十三颗」和「2012」原本不是一个故事。所谓「巫族」这套称呼，属【构思】或外围演绎层，没有可核验的对应原典 叙事，不是史料
② 实物鉴定 大英博物馆 2005 年、英美团队 2008 年、史密森尼 Jane MacLaren Walsh 2010 年用电子显微镜 / CT / 紫外 / SEM 检查：眼窝、牙齿、颅骨上有旋转轮留下的规则弧线；史密森尼那颗检出碳化硅（现代合成磨料）；米歇尔-黑吉斯头骨带高速金刚石涂层工具痕迹，原料是巴西水晶，其本人信件写明 1943 年在伦敦拍卖会买下。全球约 12 件同类，凡提交科学检测的大型水晶头骨，没有一颗被认证为前哥伦布时期遗物 水晶是真的，古代身份是假的
③ 石英会「记」什么 石英的压电性让它稳定振动，所以能做钟表晶振——那是产生信号，不是保存数据。它真正会记的是缺陷中心（氧空位、过氧键等）累积的辐射剂量，用来做热释光 / ESR 测年，读出来的是「这块石头形成于什么化学环境、受过多少辐照、大概多老」。顺带一提：石英不是有机物，不能碳十四测年，年代只能靠加工痕迹反推 记剂量，不记经历
④ 能读出什么 其实是法医物证：谁摸过（指纹 / DNA）、表面油脂与划痕、什么工具加工过、大概哪年做的 读得出「谁碰过」，读不出「他在想什么」

现实里真有「水晶存数据」——但方向是反的

最接近的技术是 5D 石英光存储 / 玻璃硬盘：飞秒激光在熔融石英内部刻出纳米光栅，用三维坐标 ＋ 偏振 ＋ 强度共五个维度编码，单盘可达 360 TB，常温理论保存上万年、耐 1000℃、写入后不用供电，靠光学显微镜 ＋ 偏振 ＋ 机器学习解码；微软 Project Silica 用它存过《超人》，国内高校团队 2026 年已小规模量产。

关键就一句

那 360 TB 是有人用激光一比特一比特写进去的。它是 WORM（一次写入多次读取），没有写入器、没有格式说明、没有读盘设备，一块再纯净的石英也只是一块石头。

这正好落在张氏体系自己的判据里：全息 / 5D 光存储仍是「用物体粒子存」，按果克体系自身标准属于「落后」那一类。而且这套体系自己也没解决这个问题——果克人的「信息中心」并没有被取消（§12 详述）。

那「记忆」那头呢？真能读一点，但条件苛刻到几乎不沾边

  • fMRI ＋ 多体素模式分析能在活人、实时、扫描中、且事先拿同一批素材训练过分类器的前提下，分辨他此刻在回忆三段短片里的哪一段；可一旦要客观判断「这张脸他到底见没见过」，能力就严重受限——斯坦福那篇专门把这条列为边界条件。
  • 7T 高场 MRI 也只是把印迹（engram）看得更细，学界仍在争这算「直接看到记忆」还是「只看到间接表征」。
  • engram 本身不是记忆，只是记忆存放的地方；记忆是分布式、且每次回忆都在重构的。
  • 至于从死者或遗物里提取——现有判断是「技术上极具挑战」，连完整人脑模型都还没有，更别说一块被摸过的石头。

这个例子反过来把整件事照得最亮

现实里我们连「从一块石头里读出使用者记忆」都做不到，倒已经能用激光往石英里写 360 TB 并保存十万年。
写入是工程，回忆是叙事，两者别混。——这句话可以当作整个「空间存信息」讨论的收束。

四问里最狠的是第二问

四问之中，「什么格式」这一问最不留情面，因为它不接受任何比喻。你可以说「信息不需要形式」，但一旦不需要形式，「读取」这个词就失去了操作含义——没有格式，就没有「解对／解错」，也就没有可重复性。这就是为什么「不需要形式」听上去最玄妙，实际上是最快自我取消的一句。

第三问则专门用来分离「真读取」与「生成」：不同团队、不同设备、不同先验，能不能收敛到同一份结果。CMB 能（六个参数反复被独立复现），5D 石英能（换台显微镜读出来还是那串比特），水晶头骨不能，果克不能。

§11　最小可证伪判据（四问 ＋ 七个数）

这一节是整场讨论的落点：把「空间能存信息」变成一个能被打死的命题。判据分两层，先四问过筛，再七个数定量。任一项给不出，就还停在【构思】，不是工程。

第一层：四问（过筛）

未来 → 读者就在过去，违反因果； 若写入时刻在过去 → 它已不是「未来」，且量子测量与混沌让「定稿」不成立。
图 3｜四问。前三问筛「能不能读」，第四问专门筛「含未来」这个附加主张。四问的排列不是随意的：Q2 最狠（否定格式即自我取消），Q3 最实用（换个种子就能测）。

第二层：七个数（定量）

再往下是立项前必须交的七个数字。注意这里没有一条是「理论对不对」——全是工程参数。这也是本页与首页「40 项对照」的分工：那边判理论，这边判「能不能做成设备」。

§12　现实里能落地的那一半

审到这儿如果只停在一个「不行」，那是浪费。这场讨论真正的收获是：果克那句话里有一个成分是对的，而且正在被实现——只是实现方式与字面相反。

那一半是对的：「去终端化」

字面版（不成立）

「任意一处空间存全宇宙所有信息」——需要无穷容量、零延迟、无介质。
三条定律级判决各自否掉一条。

工程影子（正在量产）

分布式纠删码 ＋ 内容寻址 ＋ CPO 光互连 ＋ 全息 / 5D 归档＝ 做到「随用随现、不用即消失」。
去的是终端与机房的可见性，不是介质。

这条线还有一段很有意思的旁支：对话前几轮本来在聊数据中心怎么能变小、变静、几乎不耗电，结论是「小、静、省电」不是三个目标，是同一个变量的三个切面——

耗多少电 → 就变多少热 → 要多大散热面积 → 要不要风扇/冷却塔/燃机 → 产生多大低频嗡鸣和占地

P → Q → A → 噪音 → 体积

把 P（功率）从源头压下去，后面四项会一起塌缩。而压 P 压到某个程度，消失的不是「更小的机房」，而是「机房」这个物种——计算会像水电一样嵌进建筑、路面和卫星里。

这一段的真正价值：它把果克的叙事翻过来了

果克最诱人的从来不是「空间能装下一切」，而是「随用随现、不用即消失」。而这句话能成立的前提，不是「背景辐射里存着记忆」，是「信息压根没被搅成热」。

更要紧的一点：果克人的「信息中心」并没有被取消。原典里他们仍要靠「全球信息网」「人工场扫描」去接一个中心——他们也没做到「无介质」。所以「空间即介质」这句话，在它自己的体系里也只是把介质藏到了边界之后，不是取消了介质。

这也正是现实版能做到的那一半：去终端化的交互，而不是「去介质的存储」。

三档排期（不写科幻）

时段能做的是什么对应哪一圈
0–5 年 把「看不见的机房」交付出来：分布式纠删码 ＋ 内容寻址 ＋ 光互连 ＋ 冷归档；交互层做到「随用随现」。物理层一个字不改 回应第 ③ 圈：不是去背景辐射里考古，是让机房在感知里消失
5–15 年 把「暂寄在场里」从毫秒推到可运维、带纠错：可寻址、保持相干的量子存储。现实数字：60 MHz 带宽下约 94.6% 效率 / 98.91% 保真；室温里德堡圆态寿命约 11.5 ms 但相干仍卡在百微秒量级；STA 能把写入压到 250 ns 回应第 ④ 圈的反面：别让它热化。趁信息还是信息的时候接住
15 年＋ 全息编码只做理论，不承诺硬盘。已有原型（全息纠错码在离子阱上跑通、验证全息熵关系），但它是体→边界的冗余映射，不是可读写存储器，且只在反德西特时空严格成立 第 ① / ② 圈的归宿：留在本体论层，不产生工程后果

一张「信息从哪来到哪去」的对照

果克原典：  任意一处空间 ──[人工场扫描]──> 大脑直连        （无写入、无格式、无设备）
现实已有：  物理介质     ──[编码+纠错]──> 可寻址存储      （有写入、有格式、有设备）
现实已有：  宇宙余晖     ──[探测器+统计]──> 六个参数        （有测量、无编址、无事件）
未来方向：  未热化的态   ──[量子存储]──> 毫秒级可读        （有对象，但寿命极短）

四行并排，差别一眼可见：第一行缺的是「谁写、什么格式、什么设备」；后三行缺的只是「寿命与规模」。这就是「构思」与「工程」的分界，也是这张表存在的意义——它把一句玄学，换成了三行可查的技术现状。

§13　判定与诚实边界

总判定

本体论层（信息属于宇宙）：不判真假。它成立，但等价于「信息存在于存在之中」——重言式，不产生任何工程后果。
工程层（能否写入、寻址、读出、擦除）：判不成立。五条要件全缺，三处内部断裂，三条定律级判决无一被绕过。
可用性：作为思想实验与叙事母题成立且有力（「随用随现、不用即消失」是真正值钱的那半句）；作为技术路线不成立。

一句话收尾

果克那句「任意一处空间存全宇宙过去现在未来」，与现实的最短距离，大概就是：
我们能从天上那层最老的微波里，拟合出六个参数。

宇宙能含信息，不能存信息；黑洞能记账，不能回忆；CMB 能体检，不能考古；水晶能记剂量，不能记心事。
而真正值钱的那半句，不是「空间能装下一切」，是「随用随现、不用即消失」——它正在被实现，只是实现方式是把介质藏起来，不是把介质取消。
