## 四、方法论：三条硬规矩

1. **数字必须能复算**。凡出现量级、比值、阈值，都在文内给出算式或来源行号；
   拿不到的写「未取到」，不写「约为」。
2. **圈内主张与主流实证分轨并列**，不混在一张表里排序。张祥前的话与 PRL 的话各占一栏，
   谁对谁错交给读者，但**不许让读者误以为二者已被同等验证**。
3. **每条结论附证伪条件**。写不出「什么情况下这句话算错」的，就标「不可证伪」，
   而不是包装成「深刻」。
