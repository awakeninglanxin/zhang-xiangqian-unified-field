## 2. 核心结论：**没有，而且恰好相反；不是优势少一点，是范畴不同**

| 判据 | 真空要求 | 这套公式 |
|---|---|---|
| 洛伦兹不变 | 双曲型 PDE `∂μ∂^μφ + V′(φ)=0`、洛伦兹标量、可逆哈密顿演化 | ODE 流 `dX/dt=f(X)`，一开头挑了「外鞘静止系」；呼吸 / 截面 / 周期 / 整数圈依赖全局绝对同时性；w 里没有 c |
| 无耗散 | 刘维尔定理，相体积守恒 | 奇怪吸引子存在的前提就是 `∇·f<0`（相体积收缩）；软壁是承重墙，`k_R=k_Z=0` 时 5/5 NaN、CFL 1.49×10⁷⁴ |
| 混沌 | 相变期经典场可有**场位形的时空混沌** | 奇怪吸引子上的**低维轨道**，两回事 |

四条具体冲突：① 呼吸 λ(t)=sin²(πt/T) 全场同一时刻变形 = 全局绝对同时性；② 庞加莱截面 z=L / 周期 T* /
锁相整数圈 k 依赖同一时间切片，boost 后截面不同时、周期不守恒、闭合解不再闭合；③ w=Ω₀/(ρ+r_c)^{3/2}
里没有 c，非相对论造形模型；④ §5 把欧氏 3D 曲面套进 Alcubierre 度规当泡壁输入，两层不兼容，且泡壁
需违反 NEC 的负能量，与「吸引子自动贴壁」是两码事。

散度数值：Lorenz −(σ+1+β)=−13.667 → e^{−13.67t}；Thomas −3b=−0.6246 → e^{−0.625t}；
Rössler `x−5.5` 吸引子上恒负。无耗散（哈密顿/刘维尔）最多是 KAM 环面、同宿缠结、Arnold 扩散；
ABC 流无耗散（∇·u=0、Beltrami、流线混沌）但仍是非相对论流体方程且挑流体静止系。

**收尾判据**：看到「吸引子」先找散度，负的就是耗散；看到「外鞘 / 截面 / 周期 T / 全局呼吸」＝已挑静止系；
看到「真空」＝要求洛伦兹标量 + 可逆哈密顿演化，两样都不给。

## 1 洛伦兹不变这关：它不是场方程，是 ODE 流

洛伦兹不变的真空得写成双曲型 PDE：

$$\partial_\mu\partial^\mu\phi+V'(\phi)=0,\qquad \mathcal L=\tfrac12(\partial\phi)^2-V(\phi)$$

里面没有「外鞘」「壁」「轴」「截面」，也没有全局同步的 $t$。而文档里的场是 $d\mathbf X/dt=\mathbf f(\mathbf X)$，柱坐标 $(\rho,\theta,z)$、固定 $\rho_e(z)$、差动旋转 $w=\Omega_0/(\rho+r_c)^{3/2}$——**它一开头就挑了一个「外鞘静止系」**。真空不能挑首选系，这是上一轮 U4 那条。

三个具体冲突：

- **呼吸 $\lambda(t)=\sin^2(\pi t/T)$** 是全场同一时刻一起变形，等于全局绝对同时性；相对论里没有这个 $t$。
- **庞加莱截面 $z=L$、周期 $T^\*$、锁相整数圈 $k$** 全都依赖「同一个时间切片」。换一个 boost 的观测者，截面不同时、周期不守恒，闭合解不再闭合。
- **$w=\Omega_0/(\rho+r_c)^{3/2}$ 里根本没有 $c$**。内快外慢的剪切若照搬到相对论，得加约束 $\Omega\rho<c$；文档没有，说明它本来就是非相对论造形模型。

§5 把轮廓套进 Alcubierre 度规，是**拿一个欧氏 3D 曲面去当泡壁输入**。度规本身协变，但输入轮廓来自耗散 ODE + 全局呼吸，两层不兼容；而且泡壁要违反 NEC 的负能量，这跟「吸引子自动贴壁」是两码事。

## 2 无耗散这关：吸引子 ≡ 相空间收缩

奇怪吸引子能存在，必要条件就是 $\nabla\!\cdot\!\mathbf f<0$（相体积收缩、有吸引域）。给三个数：

| 系统 | 散度 | 每单位时间体积 |
|---|---|---|
| Lorenz | $-(\sigma+1+\beta)=-13.667$ | $e^{-13.67t}$ |
| Thomas | $-3b=-0.6246$ | $e^{-0.625t}$ |
| Rössler | $x-5.5$，吸引子上恒负 | 收缩 |

你文档里的场同理：① 径向吸引 $-\rho(\cdots)$ 是压缩项，② 软壁 $-k_Rt_1$ 更是强压缩。**文档自己那张表就是最硬的证据**：$k_R=k_Z=0$ 时 **5/5 第一步就 NaN**、CFL 冲到 $10^{74}$——「软壁是承重墙」翻译成物理语言，就是**靠耗散把相空间压进有界域**。

而无耗散（哈密顿/刘维尔）系统相体积守恒，**根本不会有奇怪吸引子**：最多是 KAM 环面、同宿缠结、Arnold 扩散那种「混沌但无吸引域」的结构。ABC 流正是这一类——稳态 Euler 解、$\nabla\!\cdot u=0$、Beltrami、流线混沌；它是无耗散的，但一是非相对论流体方程、二挑出流体静止系，仍不洛伦兹不变。

所以「洛伦兹不变 + 无耗散 + 混沌」不是不能共存：经典 Yang–Mills 场的时空混沌、相变期格点里的湍流级联都可以。但产物是**场位形的时空混沌**，不是「一条被吸到低维奇怪吸引子上的轨道」。

## 3 公平讲：它的优势是真的，只是不在物理那栏

文档里这几条我认，而且做得漂亮：

- **§1.4 解耦定理**：$\varepsilon=0$ 时 $\Theta=\Omega_0 I$ 严格成立，实测漂移 0.000002%
- **§3 相似律**：10 个无量纲组，$J\propto s$、$\Omega_0\propto s^{3/2}$、$\varepsilon_V\propto s^2$ 是量纲定理不是拟合
- **§4 精确锁相 / Newton 打靶 / 软壁 $C^\infty$ 正则化 / 安全域回归**

但注意——**每一条都恰好依赖被否掉的那两样**：闭合环是耗散吸引子上的周期轨道；锁相整数圈依赖绝对时间；外鞘不变流面依赖固定边界。真换成洛伦兹不变无耗散的标量场，这四把钥匙一起失效：没有吸引子、没有唯一闭合目标、没有全局截面、锁相要改成作用量–角变量的共振条件。

它的定位是**造形 / 动画 / 几何 CAD 级的优秀结构**，不是真空结构。
