## 一、判据：五条要件（判「存」是否成立）

一次真正的存储必须同时满足五条，缺一条就退化成「含」：

| # | 要件 | 要求 | 张氏主张 |
|---|---|---|---|
| ① | 可制备 | 能主动把载体置到指定态 | 无（只能被动接收余晖） |
| ② | 可区分 | 至少两个可分辨态，且能读出是哪一个 | 无 |
| ③ | 可寻址 | 能指定「这一处」而不扰动别处 | 无，且与「每点含全部」冲突 |
| ④ | 可复位 | 用完能擦回空白 | 无（且「无观察者即无时间」使复位无时刻可定） |
| ⑤ | 有环境 | 有外部接收擦除排出的熵 | 无（载体放大到宇宙，环境消失，T 写不出） |

**一句判据**：含是状态，存是操作；操作需要内外之分。

## 二、判据：四问（过筛）

| # | 问题 | 作用 |
|---|---|---|
| Q1 | **谁写的？** | 写入者必须是一个可指认的动作，不能是「自然发生」 |
| Q2 | **什么格式？** | 没有格式 = 没有「解对／解错」= 没有可重复性。**最狠的一问**：说「信息不需要形式」，等于自动放弃「读取」这个词 |
| Q3 | **哪台设备能重复读出同一份？** | 分离「读取」与「生成」的唯一办法：换设备、换团队、换先验，结论应收敛 |
| Q4 | **哪一刻写的未来？** | 自带二难：写在未来 → 读者在过去（违反因果）；写在过去 → 已不是「未来」 |

**Q4 二难展开**：写入时刻若在未来，读者就在过去，违反因果；若在过去，它已不是「未来」，且量子测量与混沌让「定稿」不成立。这一枝不靠算力能绕。

## 四、判据：`P → Q → A → 噪音 → 体积` 链

「小、静、几乎不耗电」不是三个目标，是**同一个变量的三个切面**：

```
耗多少电 → 就变多少热 → 要多大散热面积 → 要不要风扇/冷却塔/燃机 → 产生多大低频嗡鸣和占地

P  →  Q  →  A  →  噪音  →  体积
```

推论：只在末端加隔音罩，等于给发烧病人敷冰袋。把 P 从源头压下去，后面四项一起塌缩。
极限推论：P 压到足够低，消失的不是「更小的机房」，是**「机房」这个物种**。

## 五、数字：热力学与信息论地板 🟢

| 量 | 值 | 说明 |
|---|---|---|
| `kT ln2`（300 K） | **2.87×10⁻²¹ J** | 擦一比特的最小耗散。k=1.380649×10⁻²³，ln2=0.6931 |
| 同上（2.7 K，即 CMB 温度） | **≈2.6×10⁻²³ J** | 比室温低约 100 倍，**但不是零**（第三定律不让 T 到 0） |
| 今天 CMOS 每次开关 | 10⁻¹⁶ ~ 10⁻¹⁵ J | 比地板大 5–6 个数量级 ⇒ **卡住数据中心的不是 kT ln2**，是漏电、搬运、散热 |
| Landauer 原理内容 | 擦除 1 bit ≥ kT ln2 | 只对「擦」收税；存着、读、复制理论上可不付（只要可逆） |
| 数据处理不等式 | `I(X;Z) ≤ I(X;Y)`（X→Y→Z 马尔可夫） | 后续处理不创造上游信息。狠话版：**运行更久不会扩大一个函数的值域** |

## 六、数字：容量上限 🟢

| 量 | 表达式 | 要点 |
|---|---|---|
| 贝肯斯坦界 | `S ≤ 2πk_B·R·E/(ℏc)` | 有限系统信息量有上限 |
| 黑洞熵 | `S = A/(4 l_P²)` | 每 4 个普朗克面积约 1 bit；**∝ 面积，不 ∝ 体积** |
| 全息原理 | 体信息非局域编码在边界 | 四个「不」：编码在边界而非任意一点／非局域冗余而非随机存取／容量有限／只在 AdS 严格成立 |
| 我们的宇宙 | 德西特 | 没有 AdS 那种类时边界，dS/CFT 一致性与 dS 全息 no-go 仍是开放问题 |

**关键判别**：张氏「二维空间零体积 → 零距离 → 弥漫任一处 → 无穷容量」与全息原理**方向相同、结论相反**——全息给的是「有限密度、有限总量」，他给的是「无穷」。

## 十一、五圈闭环（对话的叙事骨架）

| 圈 | 换的载体 | 补上了什么 | 被什么挡住 |
|---|---|---|---|
| 1 | 宇宙整体 | 不用另找介质 | 没有外部执行写入；可区分态数=1 |
| 2 | 黑洞 | 视界给了内外之分 | 无毛定理：只记 M/J/Q，不记内容 |
| 3 | 背景辐射 | 环境回来，T=2.7K | CMB 变成环境 ⇒ 宇宙又不是载体 |
| 4 | 未来技术 | 信息确实没删除 | 解码指数壁垒 + 读者也在宇宙里 |
| 5 | 水晶头骨 | 内外终于干净 | **没人写进去** |

**收敛结论**：宇宙能含信息，不能存信息；黑洞能记账，不能回忆；CMB 能体检，不能考古；水晶能记剂量，不能记心事。
